## What changed
- Added `SystemSettingsController`:
  - `GET /api/settings/system` (`settings.system.view`: Administrator, Accounting);
  - `PATCH /api/settings/system` (`settings.system.manage`: Administrator).
- Settings are stored as `system_settings` keys:
  - `school.name`, `school.address`;
  - `receipt.title` (`Official Receipt` | `Acknowledgment Receipt`), `receipt.paper_size` (`Letter` | `A4`);
  - `email.sender_name`, `email.sender_address`, `email.daily_send_limit` (integer >= 0).
- Absent keys return `null`; no defaults are invented.
- `nextReceiptSequence` / `nextReceiptNumber` are read-only.
  - They come from `receipt_sequences.last_sequence + 1`, in the existing `OR-YYYY-NNNNNN` format with the current Manila year.
  - Sending either field returns 422.
- PATCH is partial. One audit entry records only the keys that changed (before/after), in the same transaction as the writes.
